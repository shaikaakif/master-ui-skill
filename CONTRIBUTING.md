# Contributing to Master UI Skill

Thanks for helping improve a design constitution for coding agents.

## How to contribute

1. Fork the repository and create a feature branch.
2. Make your change to `SKILL.md` (or docs).
3. Keep edits consistent with the existing articles and workflow.
4. Open a pull request with a clear summary of what changed and why.

## Guidelines

- Prioritize product truth, accessibility, and working behavior over decoration.
- Do not add dependencies or large libraries unless a specific task justifies them.
- Keep the skill readable, versioned, and honest about unverified claims.
- Report known gaps rather than claiming full compliance.

## Code of conduct

Be respectful and constructive. Harassment and low-effort spamming of PRs are not welcome.
